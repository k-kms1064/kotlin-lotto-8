# 로또

## 구현 기능 목록

- 구입 금액 입력 및 검증 (`1000`원 단위)
- 구입 금액에 따른 로또 개수 계산 및 발행
- Random API를 이용한 6개 중복 없는 번호 생성 (1~45)
- 구매한 로또 번호 오름차순 정렬 후 출력
- 당첨 번호 및 보너스 번호 입력
- 당첨 번호와 보너스 번호를 이용한 등수 판정
- 등수별 상금 계산 및 합산
- 수익률 계산 (소수점 둘째 자리 반올림)
- 당첨 통계 및 수익률 출력 (금액은 천 단위 콤마 포함)
- 프로그램 전체 예외 처리 (`[ERROR]` 메시지 출력 후 재입력 가능)

## 예외 처리

- `[ERROR]` 형식으로 모든 예외 메시지 출력
- 구입 금액이 `1000`으로 나누어 떨어지지 않으면 예외 발생
- 로또 번호가 1~45 범위를 벗어나면 예외 발생
- 로또 번호 중복 시 예외 발생
- 보너스 번호가 당첨 번호와 중복될 경우 예외 발생
- 숫자 이외의 입력값(`1000j` 등) 입력 시 예외 발생
