# 로또

## 구현 기능 목록

- 구입 금액 입력
- 구입 금액에 따라 로또 개수 계산
- Random API로 6개 중복 없는 숫자 생성
- 당첨 번호 입력
- 보너스 번호 입력
- 구매한 로또 출력
- 당첨 통계 출력
- 번호 오름차순 정렬
- 일치 개수와 보너스 여부로 등수 판정
- 등수별 상금 합산
- 수익률 계산 및 출력

## 예외 처리
- [ERROR] 형식으로 메시지 출력
- 금액이 1000으로 나누어 떨어지지 않으면 예외 처리
- 로또 번호가 1~45 범위를 벗어나면 예외 처리
- 중복 번호 예외 처리
- 보너스 번호 중복 예외 처리
